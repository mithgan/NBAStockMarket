# Current-engine comparison correction — September 10, 2026

The comparison scripts now include the same inputs as the existing game engine. No game-scoring coefficient or economy rule changed.

- Blend and plus-minus comparisons now include the engine's `minutes = -0.15` coefficient. Previously, a 30-minute game incorrectly avoided a 4.5-NetPoints deduction.
- The margin CSV loader now keeps `three_pa`, and its engine comparison uses that value rather than zero. For six three-point attempts, the prior comparison missed a 0.30-NetPoints deduction.

The regression test passes valid box scores through each script's actual CSV loader and comparison function, then compares the result to `NetPointsModel`. Before the fix, six cases failed; afterward all nine pass. The affected engine/economy/simulation/study test selection passes 110 tests. An additional full-cache check verifies all 26,547 player-game rows against the engine in each script, plus unchanged margin-only blending and correct halfway interpolation.

The pure margin endpoint remains unchanged. This corrects the measurement; it does not determine a dollar conversion rate, weekly cap, individual margin attribution or trading advantage.

The older narrative reports are also marked with a notice because their numerical comparisons and recommendations were written before this correction. Their historical bodies are preserved rather than silently presented as freshly regenerated evidence.

## Reproduction

Run from the repository root with the Python environment installed:

```sh
python -m pytest -q tests/test_per_game_study_scoring.py tests/test_engine.py tests/test_per_game.py tests/test_per_game_simulation.py
python scripts/per_game_blend_sweep.py
```

Once all three seasons' raw inputs are available, regenerate both full reports:

```sh
python scripts/per_game_margin_study.py
python scripts/per_game_plusminus_study.py
```

The existing `scripts/fetch_instruments_sim_data.py --seasons 2024 2025 --skip-dnt --workers 8` can regenerate the older ESPN inputs without API credentials. That is a separate data-fetch operation; no historical data was fabricated or substituted here.
